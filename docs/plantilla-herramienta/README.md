# Plantilla documental para herramientas

Esta plantilla define los cinco documentos que debe tener la carpeta de cada herramienta cuando se documente tras completar su integración con el frontend. Copia los archivos a la carpeta de la herramienta y reemplaza las instrucciones entre corchetes con información comprobada. Elimina las indicaciones editoriales al completar cada sección; no inventes requisitos, decisiones, resultados ni pruebas.

## Archivos

1. [`requisitos.md`](requisitos.md): propósito, alcance y criterios de aceptación.
2. [`arquitectura.md`](arquitectura.md): componentes, flujo y decisiones estructurales.
3. [`api-contracts.md`](api-contracts.md): rutas, solicitudes, respuestas y errores públicos.
4. [`decision-log.md`](decision-log.md): decisiones específicas de la herramienta y referencias a decisiones globales.
5. [`test-strategy.md`](test-strategy.md): pruebas implementadas, cobertura prevista y última verificación observada.

El catálogo sigue siendo la fuente del inventario y estado de herramientas; el registro global de [`docs/fundacional/decision-log.md`](../fundacional/decision-log.md) gobierna las decisiones transversales. Esta plantilla no aprueba alcance ni comportamiento.
